## 🌟 专属定制风格

### 科研满框大字三线表风格（适合：科研汇报/企业攻关/论文答辩）

> 详细规范见 [academic-fullframe-style.md](academic-fullframe-style.md)

```
画布比例：16:9 (13.333" x 7.50")
顶栏主色：#4472C4（企业科技蓝，y:0, h:0.76）
突围强调色：#DC2626（鲜艳红，关键指标与成果标红加粗）
卡片标题色：#1E3A8A（深海蓝）
正文与线条：#1E293B（深灰黑，三线表 2.2pt/1.2pt/2.2pt）
卡片与交替底色：#F8FAFC
Ours 算法高亮底色：#EEF2FF
排版铁律：四周无虚白边距（有效内容 12.77" x 6.42"），注满框图最大字号小一号（正文 16.5~17.5pt），零底注，基准模型注年份
```

## 使用建议

| 场景 | 推荐方案 |
|------|----------|
| 科研汇报/论文答辩/企业攻关 | **科研满框大字三线表风格 (academic-fullframe)** |
| AI/技术产品发布 | 深空蓝、赛博脉冲 |
| 企业年度汇报 | 企业深蓝、商务翡翠 |
| 营销/活动策划 | 活力橙、艺术紫 |
| 学术/通用答辩 | 学术蓝 |
| 管理咨询报告 | 咨询灰 |
| 培训/教学课件 | 参考 color-system.md 的教育配色 |

---

## 配色选择决策树

```
用户场景
    ↓
[内容类型]
    ├── 科研汇报/企业技术攻关 → 科研满框大字三线表风格 (academic-fullframe)
    ├── AI/科技 → 深空蓝或赛博脉冲
    ├── 企业/B2B → 企业深蓝或商务翡翠
    ├── 营销/活动 → 活力橙
    ├── 设计/艺术 → 艺术紫
    ├── 学术/论文 → 学术蓝
    ├── 咨询/战略 → 咨询灰
    └── 其他 → 参考 color-system.md
```

---

## 重要提醒

> ⚠️ **配色只是起点，不是终点**
>
> - 这些配色方案提供视觉参考
> - 根据具体内容和品牌调整
> - 保持对比度足够（参考 accessibility.md）
> - 一页不要超过3种主色
