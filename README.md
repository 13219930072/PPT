## 风格核心要点速查 (academic-fullframe-minimal)

| 规范要点 | 核心要求 |
|---|---|
| **封面** | 100% 沿用模板原生母版与文字，不自增多余副标题 |
| **目录** | 100% 沿用模板原生三段式结构，严禁遮挡白卡，目录词极简，无细碎小字解释 |
| **顶栏** | 极大精简，仅保留首档核心词（如 `1.1 研究工作进展`），杜绝复合说明长句 |
| **版面** | 铺满白色可用空白区域，零边距浪费，左右舒展 |
| **字号** | 字号尽量选大（比溢出字号小一至二号，正文 16~19pt，标题 20~22pt），文字精简保留精华 |
| **叙事** | 坚决杜绝自夸与浮夸用语（严禁“反超6.9倍”、“首选档位”等），简简单单、客观平实陈述 |
| **图标** | 严禁任何 Emoji，使用标准学术序号（`1.`、`2.`、`•`） |
| **高亮** | 文字重点醒目红色加粗（`#DC2626`），表格关键行/指标淡黄色高亮（`#FEF08A`） |
| **视觉展示** | 一页展示一个数据集；裁掉原始图片顶部标题与图标，IR/VI/Fused 三联图极大化置顶铺满 |
| **三线表** | 标准学术黑三线，分辨率阶梯状递进（128 / 256 / ~512 原生近似），删去无关工程定向列 |
